# College major category and income

Prepared with assistance from Codex on 2026-10-27 for the optional Regression Models data analysis practice.

The analysis compares median annual earnings across college major categories in the `collegeIncome::college` dataset. It fits a linear model for log median earnings, compares it with an intercept-only model using an F test, and checks the overall association using a Kruskal-Wallis test.

The unit of analysis is a college major. These are major-level median earnings, not individual salaries. The analysis describes association and does not establish that choosing a major causes a particular income.

## Files

- `college_major_analysis.rds`: the actual command record generated by `matahari::dance_save()` after running the analysis in R.
- `analysis.R`: the analysis commands.
- `analysis_results.json`: model statistics from the executed analysis.
- `income_by_category.csv`: descriptive summaries by major category.

## Reproduce

Install `jhudsl/collegeIncome` and `jhudsl/matahari` from GitHub. In a fresh R session, set a writable working directory and run the commands in `analysis.R` at the R console, one top-level expression at a time. This lets matahari record each command. The script starts logging with `dance_start(value = FALSE, contents = FALSE)` and saves `college_major_analysis.rds` with `dance_save()`.

## Results

There were 173 majors in 16 categories, with no excluded observations. The log-income model gave F(15,157) = 1.21698, p = 0.26417, and R-squared = 0.10416. The Kruskal-Wallis test gave chi-squared(15) = 15.27239, p = 0.43198. At alpha = 0.05, these tests do not provide statistically significant evidence of an association in this supplied dataset.

The matahari record was gzip-compressed for transfer; `readRDS()` was checked to return an identical record before and after compression.
